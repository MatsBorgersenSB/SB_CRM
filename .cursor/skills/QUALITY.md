# Super skill vs skill

This folder holds both. Label honestly. A weak super skill is worse than a sharp skill.

## Super skill

Must pass **all six**:

1. **Owns a job** no other skill is allowed to do.
2. **Changes the next action** — a procedure the agent can follow, not slogans already in always-on rules.
3. **Names truth in this repo** — files, FS docs, or engines. Not generic advice.
4. **Shows good vs bad** — at least two worked examples.
5. **Fits progressive disclosure** — `SKILL.md` under 500 lines; detail in sibling files.
6. **Does not paste the constitution** — North Star and SmartAssist constitution are already always-on.

Fail any one → it is a **skill**, not a super skill.

## Skill

A protocol, checklist, or fragile how-to: Graph notify, Prisma CLI, identity mapping. Useful. Not a brain.

## Not a skill

Shared facts used by several skills belong in `.cursor/skills/references/` and are linked — never copied — into `SKILL.md`. Do not promote a company card to a super skill. Current card: [references/standard-bio.md](references/standard-bio.md).
